### B2. Фильтр с необязательными параметрами

Напишите функцию `filter_objects(objects, type_=None, max_price=None, min_area=None)`. Если параметр не передан, он не участвует в фильтрации.

| Вызов | Результат (id) |
| --- | --- |

## Блок 3. Уровень C: классы и ООП

1. Создайте класс `Property` с полями `id`, `area`, `price`, `address`.

Данные для проверки:

```python
items = [
    Property(102, 320, 12_800_000, "ул. Портовая"),
    Office(101, 45, 3_600_000, "пр. Будённовский", 5),
    Office(104, 120, 8_400_000, "ул. Садовая", 2),
```

Ожидаемый вывод:

```text

Объект №101, пр. Будённовский: 45 м², 80000 ₽/м², этаж 5
```

### C2. Каталог

Создайте класс `Catalog`, который хранит объекты `Property` и умеет:

- `add(p)` — добавить объект; если объект с таким id уже есть, не добавлять и вернуть `False`, иначе вернуть `True`;
- `remove(id)` — удалить объект по id и вернуть `True`; если такого нет, вернуть `False`;
- `find(max_price_per_m2)` — вернуть объекты не дороже указанной цены за м²;
- `total_value()` — вернуть суммарную стоимость всех объектов;
- `save(path)` — записать каталог в текстовый файл, по объекту на строку.

```python title="Проверка (использует items из C1)"
catalog = Catalog()
for p in items:
    assert catalog.add(p) is True
assert catalog.add(items[0]) is False
assert catalog.total_value() == 24_800_000
assert sorted(p.id for p in catalog.find(70000)) == [102, 104]
assert catalog.remove(999) is False
catalog.save("catalog.txt")
```
