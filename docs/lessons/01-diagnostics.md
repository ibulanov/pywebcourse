**2.1. Средняя стоимость запаса**

Функция должна вернуть среднюю стоимость запаса на одну товарную позицию: цена, умноженная на остаток.

```python
def avg_stock_value(products):
    total = 0
    for p in products:
        total =+ p["price"] * p["stock"]
    print(total / len(products))

result = avg_stock_value(products)
print(round(result, 1))
```

### B4. Табель бригады и ведомость

В файле `timesheet.txt` записан табель строительной бригады за месяц. Каждая строка имеет формат `имя;часы;ставка в час`. В файле может встретиться пустая строка.

```text title="timesheet.txt"
Андрей;160;450
Олег;172;400

Сергей;96;450
Павел;180;520
Иван;120;380
```

Напишите две функции:

- `load_timesheet(path)` читает файл и возвращает список словарей с ключами `name`, `hours`, `rate`; часы и ставка должны быть числами;
- `save_payroll(workers, path, min_pay)` записывает в файл ведомость: только тех, кто заработал за месяц не меньше `min_pay`, по одному на строку в формате `Андрей: 160 ч × 450 ₽ = 72000 ₽`.

```python title="Проверка"
workers = load_timesheet("timesheet.txt")
assert len(workers) == 5
assert workers[0] == {"name": "Андрей", "hours": 160, "rate": 450}

save_payroll(workers, "payroll.txt", 60_000)
with open("payroll.txt", encoding="utf-8") as f:
    lines = f.read().splitlines()
assert len(lines) == 3
assert lines[0] == "Андрей: 160 ч × 450 ₽ = 72000 ₽"
```

Создайте класс `Fleet`, который хранит машины и умеет:

