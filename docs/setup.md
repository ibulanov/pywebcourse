# Как работать с материалами

Весь код курса запускается у вас на компьютере. Настройте всё один раз до первого занятия.

## Что нужно установить

1. **Python 3.12 или новее** с сайта [python.org](https://www.python.org/downloads/). На Windows при установке отметьте галочку **Add python.exe to PATH**.
2. **Редактор кода.** Подойдёт [VS Code](https://code.visualstudio.com/) с расширением Python или PyCharm Community.

Проверьте, что Python установлен. Откройте терминал и выполните:

```bash
python --version
```

Должна появиться версия, например `Python 3.13.1`. На macOS и Linux команда может называться `python3`.

## Папка курса

Заведите одну папку для всего курса, а в ней отдельную папку на каждое занятие:

```text
pywebcourse/
├── lesson-01/
│   ├── data.py
│   ├── objects.txt
│   └── solutions.py
├── lesson-02/
└── ...
```

Файлы для урока скачивайте со страницы урока в его папку. Если скачанный файл открылся в браузере, а не сохранился, нажмите ++ctrl+s++ (на macOS ++cmd+s++).

## Как запускать код

Откройте папку занятия в редакторе и запустите файл кнопкой ▶ или из терминала:

```bash
python solutions.py
```

Чтобы использовать данные из `data.py` в своём файле, импортируйте их. Оба файла должны лежать в одной папке:

```python
from data import objects

print(len(objects))  # 5
```

## Как проверять себя

В заданиях есть блоки «Проверка» с командами `assert`. Скопируйте их в конец своего файла и запустите.

```python
assert 2 + 2 == 4        # верно: ничего не произойдёт
assert 2 + 2 == 5        # неверно: программа остановится с AssertionError
```

Если программа отработала молча, все проверки пройдены. Если появилась ошибка `AssertionError`, посмотрите номер строки в сообщении: он покажет, какая проверка не прошла.

!!! warning "Кодировка файлов"
    Файлы с русским текстом всегда открывайте с `encoding="utf-8"`. Без этого на Windows вместо букв может появиться нечитаемый набор символов.
